# Como Instalar e Executar

## 1. Requisitos
- Python 3.x instalado (ja instalado)
- Windows 10 ou 11

## 2. Baixar os arquivos
1. Acesse: https://github.com/msomerib/msomerib/tree/claude/prodrama-a1rq65
2. Clique no botao verde **Code**
3. Clique em **Download ZIP**
4. Extraia a pasta para onde preferir (ex: `C:\Moradias`)

## 3. Instalar dependencias
Abra o Prompt de Comando na pasta extraida e execute:
```
pip install openpyxl
```

## 4. Executar o programa
```
python main.py
```

O banco de dados `moradias.db` sera criado automaticamente na mesma pasta.
